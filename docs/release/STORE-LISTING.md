# 스토어 등록 초안

상태: DRAFT. 최종 이름·패키지·개발자·지원 이메일·권리·연령 확인 전. 업로드/공개하지 않음.

앱 이름 후보: 별 키우기 · ZeroStar

짧은 소개: 쉬는 동안 자란 별을 만나고 여섯 빛깔 도감을 완성하세요.

상세 설명:

작은 별씨에서 시작해 나만의 조용한 우주를 완성하세요.
별빛은 자동으로 모이고, 빛 모으기 강화로 별을 더 빠르게 키울 수 있어요.
완성한 별을 도감에 남기면 다음 별은 조금 더 힘차게 자랍니다.
새벽별부터 은하별까지, 정해진 순서로 여섯 별을 만나보세요.

• 별빛 하나, 강화 하나로 간단하게 즐기는 방치 게임
• 6단계 성장과 서로 다른 장식을 가진 6종의 별
• 앱을 닫아도 최대 8시간까지 별빛 생산
• 무료, 인앱결제 없음, 홈 화면 배너 광고 포함
• 인터넷 없이 게임 진행 가능. 광고에는 네트워크를 사용합니다.
• 움직임 줄이기와 효과음 끄기 지원

현재 진행과 설정은 이 기기에만 저장합니다. 앱 삭제, 데이터 지우기 또는 기기 변경 시 복구를 보장하지 않습니다. 현재 로그인이나 서버 복구는 제공하지 않습니다.
여섯 별을 모두 등록하면 자동 생산을 마치고 마지막 별과 완성 도감을 감상할 수 있습니다.

릴리스 노트 초안: 여섯 빛깔의 별을 키우는 첫 번째 우주를 준비했습니다.

시각 자료: 실제 debug 앱 홈/성장/도감/설정 캡처4장을 assets/screenshots에 확보했다. 최종 출시 AAB 확정 후 다시 캡처해 사용한다. 예시 목업으로 실제 화면을 대체하지 않는다. 아이콘 512×512와 대표 이미지 1024×500은 assets 폴더에 초안 제작·육안 검수했다. 실제 앱 캡처가 아니다. 제출 시 공식 규격을 다시 확인한다.

신고 초안: 광고 있음 / 인앱결제 없음 / 로그인 불필요 / 앱 액세스 제한 없음. 대상 연령·콘텐츠 등급·한국 출시 요구는 소유자 및 해당 콘솔 확인 전 미완료.
