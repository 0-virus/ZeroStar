# 개인정보처리방침 초안

상태: 공개 전 초안. 운영자명·연락처·효력일·공개 URL을 소유자가 확정해야 합니다.

ZeroStar는 기기 내에 별빛, 강화, 도감, 마지막 정산 시각, 효과음·움직임 설정과 안내 확인 상태를 저장합니다. 자체 게임 서버나 사용자 계정은 사용하지 않습니다. 진행 데이터의 자동 백업과 기기 전송을 제외하도록 설정합니다. 앱 삭제·데이터 지우기·기기 변경 시 복구를 보장하지 않습니다.

앱에는 Google의 배너 광고와 동의 관리 SDK가 포함됩니다. 광고 서비스는 광고 제공, 측정, 서비스 진단 및 부정행위 방지를 위해 IP 주소(대략적 위치 추정), 앱과 광고 상호작용, 진단 정보, 기기·계정 식별자 등을 수집·공유할 수 있습니다. Google의 안내에 따르면 전송은 TLS로 암호화됩니다. 구체적인 처리는 지역, 동의 상태, 연령 설정, SDK 버전과 광고 제공 방식에 따라 달라집니다. 게임이 로컬 저장이라는 이유로 모든 데이터가 수집되지 않는다는 뜻은 아닙니다.

필요한 경우 앱 실행 시 광고 동의 양식을 제공합니다. 개인정보 선택이 요구되는 지역·상태에서는 설정의 ‘광고 개인정보 선택’에서 변경할 수 있습니다. 광고를 요청할 수 없거나 네트워크가 없더라도 게임 진행은 가능합니다. Android 설정에서 광고 ID를 삭제하거나 재설정할 수도 있습니다.

설정의 ‘전체 초기화’는 게임 진행과 설정을 지웁니다. 이는 광고 사업자가 이미 보유한 정보의 삭제를 의미하지 않습니다. 광고 사업자의 보관·삭제·국외 처리 사항은 Google 정책과 관련 선택 수단을 함께 참고해야 합니다. 앱의 정책 링크를 열면 외부 브라우저가, 문의 이메일을 보내면 이용자가 선택한 메일 서비스가 각자의 정책에 따라 정보를 처리합니다.
