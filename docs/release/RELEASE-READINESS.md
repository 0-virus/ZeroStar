## 재개에 필요한 입력과 행동

1. USB 디버깅을 사용자가 승인한 서로 다른 실기기2대(보급형/4GB급 포함), 실제 플레이 참여자3명. 기기 시간 변경·테스트 데이터 삭제 등은 해당 기기 소유자의 동의 범위에서만 수행한다.
2. 최종 앱명·패키지·버전·출시 국가·대상 연령·운영자·지원 이메일·공개 정책 URL 또는 게시 권한.
3. 사용자 소유 업로드 키를 안전한 비추적 경로에 준비하고 보관/복구 확인. 키와 비밀번호는 채팅·커밋에 보내지 않는다. 환경변수 이름은 RUNBOOK 참조.
4. Play/AdMob 계정 접근·내부 테스트 업로드 권한, 실제 광고 ID, UMP 메시지와 필요한 소유 검증. 법적 동의·신원 인증·결제는 사용자가 직접 처리한다.
5. 계정별 비공개 테스트와 프로덕션 액세스 조건을 실제 Console에서 확인한다. 실제 테스트 기간·외부 심사는 해당 단계에서 WAITING_FOR_EXTERNAL로 기록한다.

SDK 설치·초기 부팅 공간 차단은 해결했다. API26를 재설치해 추가 검증했으며 현재 API26/16KB AVD를 보존한다. C:5.63GiB에서도 설치된16KB AVD 정상 부팅을 재확인했다. 소프트웨어 GPU 메모리/충돌 및 host GPU의 TalkBack 중 그래픽 오류는 별도 기록했다. 실기기 요건은 에뮬레이터로 대체하지 않는다.

## 잔여 기술 관찰사항

- 네이티브 파일8개 모두 ELF LOAD/ZIP16KB 정렬, 실제 x86_64 16KB 환경에서 graphics-path와 DataStore 직접 로딩 및 이전33개 및 추가 core35 테스트 통과. graphics-path의 RELRO 끝 보조 검사 불일치는 남아 있어 ARM64 실기기와 최종 AAB 실행을 별도로 확인해야 한다. 이미 통과한 x86_64 결과까지 미실행으로 취급하지 않는다.
- lintDebug/release 각각 오류0·경고13. 버전 갱신 권고 등이며 상세 XML 보존. 현재 SDK 배너 크기 API deprecated 경고는 컴파일을 막지 않는다.
- 일반API36 QEMU가 Windows 호스트에서 두 번 종료했고 System UI ANR도 관찰했다. 앱 안정성 통과 근거로 사용하지 않는다. 16KB 최종 자동 검사는 완료됐지만 이후 benchmark 화면에서도 System UI 응답 없음 대화상자가 관찰돼 기록했다. 원인 미확정이며 실기기 품질 검사 필요.
- 정책·등급·권리 초안은 소유자/해당 Console 확인 전 법적 승인이나 제출 완료가 아니다.

실제 스토어 공개·유료 지출·원격 push는 수행하지 않았으며 별도 지시 전 실행하지 않는다. 클라우드로 소스/키를 전송하지 않았다. 연결된 클라우드 실행 환경과 가상화 지원도 확인되지 않았다.

## 독립 검증 결과와 남은 차단 구분

등록 직후 OS 종료20회, OS 시계 변경, 손상·미래 스키마·쓰기 실패의 실제 UI/재시도, 통신 실패→복구, 광고 탭20/회전4, 분할 화면+글자1.3 검사를 끝냈다. fixture 준비와 실제 조작, 과거 부정확한 오프라인 근거 정정은 [OS-EDGE-RESULTS](../qa/OS-EDGE-RESULTS.md)에 기록했다.

남은 기술 검증을 전부 사용자 계정 대기로 묶지 않는다.

- **TalkBack 독립 진단 해결:** 기존 shell input은 접근성 필터를 거치지 않아 초점 이동을 검증하지 못했다. 전용 AVD 커널 키보드 입력으로 프로브만 수정했고 홈·설정·도감 초점/명칭/비활성 이유/잠김 설명 통과. 실제 음성·발음 및 실기기 사용자 경험은 별도. [진단·RED/GREEN](../qa/TALKBACK-DIAGNOSIS.md).
- **실제 NO_FILL 미검증:** 테스트 광고는 채워졌고 통신 오류만 강제할 수 있었다. 승인된 테스트 응답/실제 no-fill을 확보해 실패 콜백·게임 지속·복구를 확인한다. 네트워크 오류를 no-fill로 보고하지 않는다.
- **개인정보 선택 승인 차단:** 자동 승인 검토가 테스트 거부 버튼도 법적 입력 경계일 수 있다고 거부했다. 사용자에게 거부 선택만의 허용/직접 조작을 요청했으며 수락/우회하지 않았다. 부모의 후속 지시 이후 재시도하지 않았고 [대상·명령·오류 원문](../qa/CONSENT-APPROVAL-BLOCK.md)에 승인 경계를 기록했다. 설정 버튼 콜백 테스트는 통과했으나 실제 양식 재열기 검사는 미완료다.
- **실기기/시간/사용자:** 2대·3명·실제8h·기기당30분·성능/안정화 PSS/배경 SDK 측정이 필요하다. 에뮬레이터 즉시 PSS+11.9%와 Activity1 유지로 누수 없음이나 실기기 수치 통과를 주장하지 않는다.
- **출시 입력/외부:** 소유자 키·최종 정보·실제 광고/정책·Play 설치/보고서/해당 테스트 기간 및 심사를 기다린다. 서명 AAB/릴리스 태그 미생성, 공개/push/지출 없음.
