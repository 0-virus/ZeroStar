## 재개 명령과 기록

1. 승인된 기기 또는 에뮬레이터에서 `.tools/android-sdk/platform-tools/adb.exe devices` 확인. adb 허용 창은 사용자가 처리한다.
2. `./gradlew.bat -g .tools/gradle-network :app:connectedDebugAndroidTest --max-workers=2` 실행. 테스트 APK는 debug 전용이며 실제 제품 번들에 포함되지 않는다.
3. debug APK로 미검증 조작·TalkBack을 확인한다. 저장 파괴·시각 변경은 전용 테스트 데이터/소유자 동의 범위에서만 하고 원상 복구한다.
4. benchmark APK로 Perfetto/Android 프로파일러 trace·첫 조작 영상·gfxinfo·안정화 PSS·logcat을 기록한다. 실기기30분, 두 광고 조건, 실제8h는 축약하지 않는다.
5. 최종 AAB 및 업데이트·내부 테스트는 RELEASE-RUNBOOK.md에 따라 별도 실행한다.

## M4 실제 이용자 검증

3명 참여 미확보/미실행. 설명 없이 첫 강화와 목표를 찾는지, 등록 초기화 범위를 이해하는지, 복귀 동기가 있는지 기록한다. 익명 참여 번호·환경·행동·혼란·의견·수정·재검증을 남긴다. 외부 초대는 전송하지 않았다. 피드백 전 M4 완료로 표시하지 않는다.
